# BOND-API documentation

BOND-API defines the shared protocol used by the BOND software packages. The implementation and verification in this repository exercise the SABLE reference provider.

- [Runbook](runbook.md) covers setup, the reference demo, local verification, and the manuscript build.
- [Architecture](architecture.md) describes discovery, the provider lifecycle, the registries, and tagged JSON.
- [Manuscript](manuscript/README.md) indexes the canonical sources and token configuration.
- [Testing philosophy](testing_philosophy.md) explains the frozen contract and deterministic verification.
- [Standalone guide](standalone.md), [contributor instructions](agent_instructions.md), and [backlog](TODO.md) cover maintenance.
